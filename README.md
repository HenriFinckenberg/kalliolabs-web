# Kallio Labs Website

Next.js port of the Kallio Labs studio site.

## Develop

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Legacy URLs

These App Store / static-site URLs still work via rewrites:

- `/privacy-policy.html` → `/privacy-policy`
- `/onemorepho.html` → `/onemorepho`
- `/index.html` → `/`

## Deploy

```bash
npm run build
npm start
```
